# 분석 컨벤션

## 지표 정의

- 모든 지표에 분석 단위, 분자, 분모, 관측 기간을 명시한다.
- `전환율`만 쓰지 말고 사용자 전환율·세션 전환율·이벤트 비율을 구분한다.
- 구매 전환은 이벤트 발생 여부와 이벤트 순서를 구분해 정의한다.
- 카테고리·브랜드 비교 시 표본 수를 함께 제시한다.
- 소표본 그룹의 극단적 전환율은 최소 표본 기준 또는 불확실성 표시 없이 순위화하지 않는다.
- 평균과 중앙값의 차이가 중요한 가격·행동 횟수에는 두 값을 함께 확인한다.

## 해석

- 관찰 데이터에서는 `원인`, `효과`, `증가시켰다` 대신 `함께 나타났다`, `관련 신호`, `후속 검증 필요`를 사용한다.
- 결측·이벤트 누락·추적 기간 차이를 사용자 행동으로 단정하지 않는다.
- 직접 구매나 세션 간 구매가 존재하면 선형 퍼널의 한계로 명시한다.
- 데이터에 비용·마진·실험 결과가 없으면 매출 효과를 계산된 성과처럼 쓰지 않는다.

## 통계

- 검정은 의사결정에 필요한 비교에만 사용한다.
- 검정 선택과 가정을 명시하고 p-value만으로 결론 내리지 않는다.
- 효과 크기와 표본 수를 함께 제시한다.
- 반복 비교가 많으면 다중검정 문제를 검토한다.
- 검정을 수행하지 않은 탐색 결과는 기술통계 또는 분석 질문으로 표시한다.

## A/B 테스트

- 최종 핵심 발견 중 실제 제품 개입으로 연결 가능한 한 가지에만 제안한다.
- 가설, 처리군·대조군, 분석 단위, 주 지표, 가드레일, 관측 기간, 표본 산정에 필요한 입력값을 구분한다.
- 현재 데이터로 알 수 없는 기준 전환율·MDE·노출 수를 임의로 채우지 않는다.
- 필요한 로그가 없으면 실험 가능 조건과 추가 수집 항목부터 적는다.

## 시각화

- 기본 라이브러리는 기존 프로젝트와 동일하게 `plotly.graph_objects`를 사용한다.
- 배경은 흰색, 그리드는 연한 회색, 제목은 중앙 정렬한다.
- 차트 제목은 지표와 분석 단위를 드러내고, 기간·분모는 서브타이틀 또는 주석에 넣는다.
- 퍼널 단계는 동일한 순서와 색상 체계를 유지한다.
- 축 범위에는 레이블이 잘리지 않도록 여유를 둔다.
- 색상만으로 의미를 구분하지 않고 라벨·수치를 함께 표시한다.
- 차트 수를 늘리기보다 분석 질문 하나에 답하는 표·차트를 선택한다.
