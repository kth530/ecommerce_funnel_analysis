# 코스메틱 이커머스 구매 퍼널·여정 분석

공개 코스메틱 쇼핑몰의 2019-10-01-2020-02-29 이벤트 로그 20,692,840행을 분석했다. 세션 퍼널을 진단한 뒤 동일 상품의 여러 방문을 연결해 30일 대표 첫 구매 경로를 확인하고, 장바구니 알림의 첫 A/B 테스트 후보를 설계했다. 그로스 PM 요청은 공개 데이터를 실무처럼 다루기 위한 **가상 시나리오**이며 실제 캠페인 성과는 없다.

## 핵심 질문과 분석 흐름

> 한 세션의 `view → cart → purchase` 퍼널은 동일 상품의 30일 내 구매 여정을 얼마나 설명하는가? 관찰 로그로 어떤 첫 개입을 후속 실험에 올릴 수 있는가?

세션 퍼널 EDA → 동일 사용자×상품의 복수 세션 관찰 → **사용자×상품·최초 조회 후 30일**로 관찰 단위 재정의 → 대표 첫 구매 커버리지와 구매 경로 → **별도로 구성한 최초 담기 미구매 집단**의 시간 분석 → 24시간 첫 실험 후보 → 사용자 단위 배정 A/B 설계.

최종 발표용 분석은 [문제 정의·가설](notebooks/01_problem_hypothesis.md)에서 출발해 [데이터 오버뷰](notebooks/02_data_overview.ipynb), [마트 개요](notebooks/03_mart_overview.ipynb), [EDA·판단·실험 설계](notebooks/04_eda.ipynb)로 이어진다.

## 의사결정에 사용한 결과

| 질문 | 관찰 결과와 분모 | 판단 |
|---|---|---|
| 30일 대표 첫 구매를 한 세션의 세 단계가 얼마나 포착하는가? | 최초 조회 후 30일을 끝까지 관측할 수 있는 사용자×상품 5,323,764개 중 대표 첫 구매 342,457개(6.433%). 그중 같은 세션에서 조회→담기→구매가 순서대로 이어진 것은 103,974개(대표 구매의 30.361%, 적격 전체의 1.953%) | 나머지 238,483개(대표 구매의 **69.639%**)는 세 단계가 한 세션에서 모두 이어지지 않았다. 전부 다른 세션에서 구매했다는 뜻은 아니다. |
| 대표 첫 구매 직전에는 어떤 담기 경로가 보이는가? | 대표 첫 구매 342,457개 중 같은 세션 조회→담기 103,974개(30.361%), 같은 세션 담기·앞선 조회 미확인 14,291개(4.173%), 이전 세션 담기 113,677개(33.195%), 담기 미확인 110,515개(32.271%) | 이전 세션 담기는 네 **개별 경로 중** 최대다. 담기 미확인은 실제 담기 생략과 이벤트 누락 등을 구분할 수 없다. |
| 최초 담기 뒤 자연 구매율은 어떻게 달라지는가? | 최초 담기 후 7일 관측 가능 사용자×상품 4,082,470개 중 0-24시간 구매 777,301개(19.040%). 첫날 미구매 3,305,169개 중 24-48시간 구매 53,646개(조건부 1.623%) | 24시간은 운영상 일관되게 적용할 수 있는 **첫 실험 후보**다. 두 비율의 분모가 다르며 최적 시점이나 메시지 효과를 입증하지 않는다. |

대표 첫 구매 **구매자**의 경로 비중에서 알림 대상을 직접 고르지 않았다. 담기 행동이 관찰 가능하다는 점을 바탕으로, 최초 담기 후 **아직 같은 상품을 구매하지 않은** 조합을 새로 구성해 시간별 자연 구매율을 확인했다. 같은 세션 3단계 구매율 1.953%와 30일 구매율 6.433%도 담기 필수 조건이 달라 그 차이 전체를 세션 경계 효과로 해석하지 않는다.

## 첫 A/B 테스트 후보

최초 담기 후 24시간 동안 동일 상품을 구매하지 않은 조합을 대상으로 장바구니 알림을 검증한다. 기준 시점 이후 7일을 추가로 관측할 수 있는 과거 로그의 적격 **사용자×상품 조합은 3,287,385개**이며, 그중 154,517개가 이후 7일 내 구매했다. 자연 구매 기준선은 **154,517 / 3,287,385 = 4.700%**다. 이 집단은 앞 표의 대표 첫 구매 경로 집단과 다르다.

| 항목 | 후속 검증 설계 |
|---|---|
| 배정 | `user_id` 단위 1:1 무작위 배정. 적격 상품이 여럿이면 사용자당 알림 한 번으로 묶는다. |
| 처치·대조 | 담기+24시간에 알림 발송 / 미발송 |
| 주지표 | 담기+24시간 이후 7일 내 동일 상품을 구매한 **적격 사용자×상품 조합 수 / 적격 사용자×상품 조합 수** |
| 기준선·표본 | 과거 자연 구매율 4.700%, 상대 MDE 5%. 사용자 내 여러 상품 조합을 반영한 필요 표본은 총 763,479조합이며, 과거 유입 기준 모집·추적 최소 41일로 추정했다. |
| 운영·판정 | 수신 동의, 장바구니 잔존, 재고와 발송·노출 로그를 확보한다. 주지표의 사용자 군집 표준오차와 가드레일을 함께 판정한다. |

배정 단위는 **사용자**, 성과와 필요 표본의 단위는 **사용자×상품 조합**이다. 사용자 수 환산, ICC·설계효과 계산과 유입 변동 시나리오는 [최종 EDA](notebooks/04_eda.ipynb)와 [지표 정의](docs/metrics.md)에 남겼다. 실제 운영 자격 조건을 적용하면 표본과 기간을 다시 계산해야 한다. 기존 로그에는 실험 배정·발송·노출 정보가 없으므로 전환 개선이나 매출 효과는 아직 측정하지 않았다.

## 해석 한계

- 관찰 기간 내 최초 조회·대표 첫 구매는 고객의 생애 최초 행동을 뜻하지 않는다.
- 동일 시각 이벤트의 선후는 확인할 수 없어 strict `<` 순서에서 제외했다.
- 담기 미확인에는 실제 담기 생략, 이벤트 누락과 관측 시작 이전 행동이 섞일 수 있다.
- 24시간 전후 자연 구매율의 차이는 서로 다른 조건부 집단의 관찰값이다. 시점의 우열과 알림 효과는 무작위 실험으로 확인해야 한다.
