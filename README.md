# 코스메틱 이커머스 구매 전환·여정 분석

코스메틱 이커머스 5개월 이벤트 로그 2,069만 건을 MySQL에 적재하고, 세션 퍼널과 세션을 넘는 사용자·상품 구매 여정을 분석해 개선 대상과 후속 실험안을 도출한 데이터 분석 프로젝트.

---

## 프로젝트 배경

> **아래 상황은 공개 데이터를 실무처럼 다뤄 보기 위해 설정한 가상 시나리오다.** 실제 회사·담당자·업무 요청이 아니다.

**왜 이 분석을 시작했나**  
한 코스메틱 이커머스의 그로스 PM이 이런 고민을 가져왔다고 가정했다. "지금 대시보드는 고객이 한 번 접속한 동안 `view → cart → purchase`를 얼마나 이어가는지만 보여준다. 하지만 오늘 장바구니에 담고 며칠 뒤 다시 와서 구매하거나, 장바구니를 거치지 않고 바로 구매하는 경로도 있을 수 있다. 이런 경로가 보이지 않으면 실제 구매 흐름을 충분히 이해하기 어렵고, 누구에게 언제 알림을 보내야 할지도 정하기 어렵다." 그래서 하나의 세션 안에서만 보던 구매 흐름을 세션을 넘어 **사용자·상품 단위**로 다시 보는 것을 이 분석의 목표로 삼았다.

**어떻게 풀었나**  
① 먼저 2,069만 건 로그의 품질(결측·이상 가격·세션 꼬임)을 점검해 믿을 수 있는 분석용 테이블을 만들었다. ② 한 세션 안의 view→cart→purchase 퍼널로 어디서 많이 빠지고 어떤 상품·카테고리가 약한지 확인했다. ③ 같은 사람이 여러 번 접속해 산 경우를 직전 구매 기준으로 끊어, 이번 구매가 어떤 경로로 이어졌는지 겹치지 않게 분류했다. ④ 근거가 가장 강한 개입 하나를 골라 A/B 테스트로 설계했다.

**그래서, 무엇을 알게 됐나**  
30일 동일 상품 구매의 69.53%는 같은 세션에서 `view → cart → purchase`를 모두 마친 경우가 아니었다. 겹치지 않게 나눈 구매 경로는 **다른 세션 cart 연결(42.19%)**과 **현재 구매 세션 cart 연결(37.17%)**이 두 축이었다. 전체 최초 cart cohort의 구간별 다음 24시간 구매율은 0-24시간 15.413%에서 24-48시간 0.877%로 낮아졌고, 이를 바탕으로 cart+24시간 장바구니 알림을 첫 실험 후보로 정했다.

| 우선순위 | 무엇을 | 근거 |
|---|---|---|
| 1 | cart 후 24시간 동안 미구매한 사용자에게 장바구니 리마인드 | 전체 최초 cart cohort의 구간별 다음 24시간 구매율이 0-24시간 15.413%에서 24-48시간 0.877%로 낮아짐 |
| 2 | 세션 단위 퍼널 대시보드를 세션 통합 지표로 보강 | 30일 구매의 69.53%가 같은 세션 3단계 밖에서 확인 |
| 3 | 04 우선진단 카테고리 개선 유지 | 세션 밖 구매를 포함한 30일 도달에서도 낮음(1.578% vs 6.570%) |

> 관찰 로그 분석이므로 결과는 확정된 인과가 아니라 방향성·후속 검증 우선순위 제안으로 해석했다. A/B 테스트도 설계안이며 실제 실행 성과가 아니다.

## 핵심 인사이트

1. **같은 세션 3단계 퍼널은 확인된 30일 구매의 69.53%를 포착하지 못한다** - 같은 사용자·상품·관측 창을 맞춘 분모에서 같은 세션 3단계 완주율은 30일 1.960%인 반면, 세션 통합 동일 상품 30일 구매 도달률은 6.433%다. 30일 구매의 69.53%가 같은 세션 3단계 밖에서 확인된다. ([04](notebooks/04_funnel_eda.ipynb) · [06](notebooks/06_purchase_journey_analysis.ipynb))
2. **세션 안팎 cart 연결이 구매 경로의 두 축이다** - 다른 세션 cart 연결은 42.19%, 현재 구매 세션 cart 연결은 37.17%였다. 세션 밖 경로가 5.01%p 높았지만, 순위보다 서로 다른 개입이 필요한 두 경로가 모두 크다는 구성을 결론으로 사용했다. ([06](notebooks/06_purchase_journey_analysis.ipynb))
3. **구간별 다음 24시간 구매율은 첫 24시간 이후 크게 낮아진다** - 최초 cart 이후 7일을 모두 관측할 수 있는 전체 사용자에서, 각 구간 시작까지 미구매한 사용자를 분모로 계산한 다음 24시간 구매율은 0-24시간 15.413%, 24-48시간 0.877%, 48-72시간 0.501%였다. 24시간 알림의 관찰 근거지만 최적 시점이나 알림 효과를 뜻하지는 않는다. ([06](notebooks/06_purchase_journey_analysis.ipynb))
4. **반복 구매는 구매 전 cart가 덜 확인된다** - 구매 전 cart 미확인 비중이 관측 첫 구매 9.20% vs 반복 구매 25.93%로 갈린다. 탐색 구간 차이와 로그 누락 가능성이 섞여 있어 방향은 계측 신호로만 사용했다. ([06](notebooks/06_purchase_journey_analysis.ipynb))
5. **04 우선진단 카테고리는 세션 밖 구매를 포함해도 낮다** - 사용자·상품 30일 구매 도달이 우선진단 카테고리 1.578% vs 그 외 6.570%로, 04의 카테고리 진단 우선순위가 세션 간 경로를 포함한 뒤에도 유지됐다. ([04](notebooks/04_funnel_eda.ipynb) · [06](notebooks/06_purchase_journey_analysis.ipynb))

## 추천 액션

사용자별 최초 관측 cart 후 24시간 동안 동일 상품 purchase가 없는 사용자를 대상으로 장바구니 리마인드를 검증한다. 최초 cart 이후 7일을 모두 관측할 수 있는 전체 사용자에서 구간별 다음 24시간 구매율이 0-24시간 15.413%에서 24-48시간 0.877%로 낮아진 점과 같은 시각대에 일관되게 발송할 수 있다는 운영 조건을 함께 고려했다. 24시간은 첫 실험 후보이며 최적 시점이나 알림의 순증 효과가 확인된 값은 아니다.

| 항목 | 설계 |
|---|---|
| 실험 단위 | `user_id` 단위 무작위 배정 |
| 대상 | 유효 cart 이후 24시간 동안 동일 상품 구매가 없고 메시지 수신이 가능한 사용자 |
| 처치군 | 24시간 시점에 해당 상품 장바구니 리마인드 1회 발송 |
| 대조군 | 미발송 |
| 주지표 | 실험 기준 시점(cart+24시간) 후 7일 내 동일 상품 구매 사용자 비율 |
| 보조지표 | 1일·30일 구매, 사용자당 revenue, 메시지 클릭 |
| 가드레일 | 수신 거부·신고·반품/취소 대체 지표 |
| 예상 기준선 | 대조군 7일 동일 상품 구매율 2.536% |
| 표본·기간 | 상대 10% MDE 기준 총 126,548명 · 과거 평균 기준 최소 64일 · 보수적 기준 약 84일 |
| 판정 | 7일 차이와 신뢰구간·사업 기준을 확인하고, 동일 사용자의 30일 결과와 가드레일까지 함께 판단 |

## 데이터 한계

- 관찰 로그 분석이므로 행동 경로와 구매 사이의 인과관계를 확정하지 않는다.
- 관측 첫 구매·반복 구매는 5개월 안의 구분이며 생애 구매 차수와 다를 수 있다.
- 동일 시각 이벤트에 보조 순번이 없어 strict(`<`) 기준에서 제외했다.
- 장바구니 상태·검색 결과 노출·딥링크·메시지 발송 로그가 없어 직접 cart와 로깅 누락을 완전히 구분할 수 없다.
- 실제 비즈니스 임팩트는 비용·마진·실험 배정·노출 로그를 포함한 무작위 실험으로 검증해야 한다.
