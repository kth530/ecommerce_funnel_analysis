# 코스메틱 이커머스 구매 전환·여정 분석

코스메틱 이커머스 5개월 이벤트 로그 2,069만 건을 MySQL에 적재하고, 세션 퍼널과 세션을 넘는 사용자·상품 구매 여정을 분석해 개선 대상과 후속 실험안을 도출한 데이터 분석 프로젝트.

---

## 프로젝트 배경

> **아래 상황은 공개 데이터를 실무처럼 다뤄 보기 위해 설정한 가상 시나리오다.** 실제 회사·담당자·업무 요청이 아니다.

**왜 이 분석을 시작했나**  
한 코스메틱 이커머스의 그로스 PM이 이런 고민을 가져왔다고 가정했다. "지금 대시보드는 고객이 한 번 접속한 동안 `view → cart → purchase`를 얼마나 이어가는지만 보여준다. 하지만 오늘 장바구니에 담고 며칠 뒤 다시 와서 구매하거나, 장바구니를 거치지 않고 바로 구매하는 경로도 있을 수 있다. 이런 경로가 보이지 않으면 실제 구매 흐름을 충분히 이해하기 어렵고, 누구에게 언제 알림을 보내야 할지도 정하기 어렵다." 그래서 하나의 세션 안에서만 보던 구매 흐름을 세션을 넘어 **사용자·상품 단위**로 다시 보는 것을 이 분석의 목표로 삼았다.

**어떻게 풀었나**  
① 먼저 2,069만 건 로그의 품질(결측·이상 가격·세션 꼬임)을 점검해 믿을 수 있는 분석용 테이블을 만들었다. ② 한 세션 안의 view→cart→purchase 퍼널로 어디서 많이 빠지고 어떤 상품·카테고리가 약한지 확인했다. ③ 같은 사람이 여러 번 접속해 산 경우를 직전 구매 기준으로 끊어, 이번 구매가 어떤 경로로 이어졌는지 겹치지 않게 분류했다. ④ 근거가 가장 강한 개입 하나를 골라 A/B 테스트로 설계했다.

**그래서, 무엇을 알게 됐나**  
30일 안에 확인된 대표 첫 구매 342,457건 중 **69.639%는 같은 세션에서 조회→담기→구매를 모두 마친 경우가 아니었다.** 겹치지 않게 나눈 경로는 구매한 세션에서 담기 **34.534%**, 이전 세션에서 담기 **33.195%**, 담기 미확인 **32.271%로** 세 갈래가 고르게 갈렸다. 최초 담기 이후 다음 24시간 구매율은 0–24시간 19.040%에서 24–48시간 1.623%로 낮아졌고, 이를 바탕으로 담기+24시간 장바구니 알림을 첫 실험 후보로 정했다.

| 우선순위 | 무엇을 | 근거 |
|---|---|---|
| 1 | 담기 후 24시간 동안 미구매한 사용자에게 장바구니 리마인드 | 최초 담기 이후 다음 24시간 구매율이 0–24시간 19.040%에서 24–48시간 1.623%로 낮아짐 |
| 2 | 세션 단위 퍼널 대시보드를 사용자·상품 단위 지표로 보강 | 대표 첫 구매의 69.639%가 같은 세션 3단계 밖에서 확인 |

> 관찰 로그 분석이므로 결과는 확정된 인과가 아니라 방향성·후속 검증 우선순위 제안으로 해석했다. A/B 테스트도 설계안이며 실제 실행 성과가 아니다.

## 핵심 인사이트

1. **같은 세션 3단계 퍼널은 확인된 30일 대표 첫 구매의 69.639%를 포착하지 못한다** - 최초 조회 이후 30일을 끝까지 관측할 수 있는 사용자·상품 5,323,764개 중 342,457개(6.433%)에서 대표 첫 구매가 확인됐다. 이 가운데 같은 세션에서 조회→담기→구매가 순서대로 이어진 경우는 103,974개(30.361%)뿐이고, 나머지 238,483개(69.639%)는 그 밖에서 확인됐다. ([04](notebooks/04_funnel_eda.ipynb) · [05](notebooks/05_purchase_journey_analysis.ipynb))
2. **구매 직전 담기의 위치가 세 갈래로 고르게 갈린다** - 구매한 세션에서 담기 118,265개(34.534%), 이전 세션에서 담기 113,677개(33.195%), 담기 미확인 110,515개(32.271%)다. 어느 한쪽이 지배적이지 않아 단일 개입으로 덮기 어렵다. ([05](notebooks/05_purchase_journey_analysis.ipynb))
3. **담기 이후 첫 24시간이 지나면 다음 24시간 구매율이 크게 낮아진다** - 최초 담기 이후 7일을 모두 관측할 수 있는 사용자·상품 조합 4,082,470개에서, 각 구간 시작까지 미구매한 조합을 분모로 계산한 다음 24시간 구매율은 0–24시간 19.040%, 24–48시간 1.623%였다. 24시간 알림의 관찰 근거지만 최적 시점이나 알림 효과를 뜻하지는 않는다. ([05](notebooks/05_purchase_journey_analysis.ipynb))
4. **세션 단위 퍼널만으로는 여정을 설명하기 어렵다** - 세션 단위 전 구간 전환율은 2.299%, 같은 세션·같은 상품 기준은 1.636%다. 동일 사용자·상품의 17.171%가 여러 세션에 걸쳐 관찰돼, 한 세션 안에서 완결된 경로만으로는 구매 흐름의 일부만 보인다. ([04](notebooks/04_funnel_eda.ipynb))

## 추천 액션

최초 cart 후 24시간 동안 동일 상품 purchase가 없는 (사용자, 상품) 조합을 대상으로 장바구니 리마인드를 검증한다. 지표는 30일 여정 분석과 같은 사용자·상품 단위로 계산하고, 배정과 발송만 `user_id` 단위로 한다. 최초 cart 이후 7일을 모두 관측할 수 있는 조합 4,082,470개에서 구간별 다음 24시간 구매율이 0-24시간 19.040%에서 24-48시간 1.623%로 낮아진 점과 같은 시각대에 일관되게 발송할 수 있다는 운영 조건을 함께 고려했다. 24시간은 첫 실험 후보이며 최적 시점이나 알림의 순증 효과가 확인된 값은 아니다.

| 항목 | 설계 |
|---|---|
| 실험 단위 | `user_id` 단위 무작위 배정 |
| 대상 | 유효 cart 이후 24시간 동안 동일 상품 구매가 없고 메시지 수신이 가능한 (사용자, 상품) 조합 |
| 처치군 | 24시간 시점에 해당 상품 장바구니 리마인드 1회 발송 |
| 대조군 | 미발송 |
| 주지표 | 실험 기준 시점(cart+24시간) 후 7일 내 동일 상품 구매 조합 비율 |
| 보조지표 | 1일·30일 구매, 사용자당 revenue, 메시지 클릭 |
| 가드레일 | 수신 거부·신고·반품/취소 대체 지표 |
| 예상 기준선 | 대조군 7일 동일 상품 구매율 4.700% (적격 조합 3,287,385개 중 154,517개 구매) |
| 최소 검출 차이 | 상대 5% · 목표 구매율 4.935% (기준선 4.700% 대비 +0.235%p) |
| 표본·기간 | 상대 5% MDE 기준 총 763,479개(배정 기준 약 139,338명) · 과거 평균 기준 최소 43일 · 보수적 기준 약 44일 |
| 군집 보정 | 사용자 내 급내상관 0.231 · 사용자당 조합 9.36개 · 설계효과 2.93배를 표본에 반영 |
| 판정 | 7일 차이와 신뢰구간·사업 기준을 확인하고, 동일 사용자의 30일 결과와 가드레일까지 함께 판단. 표준오차는 사용자 단위로 군집 보정한다 |
| 운영 조건 | 모집 기간이 길어 계절성이 섞이지만 두 집단이 같은 기간을 겪으므로 비교는 흔들리지 않는다. 다만 기간 중 장바구니 화면·알림 문구·중복 실험 노출은 고정해야 한다 |

```text
mart_session 4,499,479행
        │
        ├─ 같은 세션 조회→담기→구매 퍼널
        ▼
mart_user_product_session 13,385,787행
        │
        └─ 대표 첫 구매 네 경로·장바구니 이후 구매 시점
```

**워크플로**: 분석 SQL은 노트북별 [`sql/`](sql/) 파일의 `-- name:` 블록으로 분리하고, 노트북은 `run()`으로 소량 집계 결과만 받아 시각화한다. 지표와 데이터 처리 방침의 단일 원천은 [`docs/metrics.md`](docs/metrics.md), cache 재현성 정책은 [`docs/cache_contract.md`](docs/cache_contract.md)에 정리했다.

## 데이터 한계

- 관찰 로그 분석이므로 행동 경로와 구매 사이의 인과관계를 확정하지 않는다.
- 대표 첫 구매는 5개월 관측 기간 안의 첫 구매이며 고객의 생애 첫 구매와 다를 수 있다.
- 동일 시각 이벤트에 보조 순번이 없어 시간 순서 조건(`<`)에서 제외했다.
- 장바구니 상태·검색 결과 노출·딥링크·메시지 발송 로그가 없어 담기를 건너뛴 구매와 로깅 누락을 완전히 구분할 수 없다.
- 실제 비즈니스 임팩트는 비용·마진·실험 배정·노출 로그를 포함한 무작위 실험으로 검증해야 한다.
