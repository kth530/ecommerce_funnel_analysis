# Tableau 대시보드 디자인 가이드

코스메틱 이커머스 구매 전환·여정 분석의 결과를 **하나의 Tableau 워크북 · 대시보드 3개**로 구성하기 위한 설계 문서.

1. 구매 흐름 요약
2. 구매 경로 탐색
3. 개선안·실험 설계

세 화면은 동일한 색상 체계·글꼴·카드·여백 규칙을 공유하며, **같은 지표의 색 의미는 화면이 바뀌어도 유지**한다. SQL·노트북의 분석 로직과 기존 수치는 수정하지 않는다. 모든 수치는 `README.md`와 `notebooks/06_purchase_journey_analysis.ipynb` 출력에서 대조한 값이다.

---

## 0. 원칙

- 분석 대시보드의 **신뢰감**을 우선한다. 뷰티풍 분홍 위주 디자인, 그라데이션, 과한 그림자, 무지개색, 불필요한 아이콘을 쓰지 않는다.
- 전체 배경 Warm Ivory, 카드 White, 제목 Deep Navy로 통일한다.
- 핵심 KPI 숫자는 해당 지표의 강조색을 쓴다.
- 데이터는 raw `events`가 아니라 검증된 마트·06 결과에서 파생한 `tableau/*.csv`만 사용한다.
- **분석 단위가 다른 집계 테이블을 물리적으로 조인하지 않는다**(건수 중복 방지). 5개 CSV = 5개 별도 데이터 원본.

## 1. 캔버스·레이아웃 규칙

### 크기: 고정 1200 × 800 (권장)

- 세 화면 모두 상단 네비 + KPI 행 + 좌우 2~3열 카드 구조라 **16:10**이 여백에 유리하다.
- Tableau Public 임베드 기본 폭(~1000–1200px)과 잘 맞아 스크롤 없이 보인다.
- 1366×768은 세로가 짧아 하단 하이라이트·A/B 흐름이 눌린다.
- 세 대시보드 모두 **동일 고정 크기**, 상단 네비 바 위치 동일.

### 레이아웃

- **Tiled(바둑판) 컨테이너 중심**으로 설계한다. Floating은 아이콘/배지 등 예외에만.
- 최상단: 가로 컨테이너에 네비 버튼 3개 + 화면 제목.
- 여백: 컨테이너 안쪽 여백 8px, 카드 간 간격 8px, 바깥 여백 16px.
- 카드: 흰색 배경 + Light Beige 테두리 1px. **Tableau 2026.1+면 모서리 약한 라운드(4px), 이전 버전이면 사각.**

### 글꼴

| 용도 | 글꼴 | 크기 | 색 |
|---|---|---|---|
| 화면 제목 | Tableau Semibold | 18–20 | `#26384A` |
| 카드 제목 | Tableau Medium | 12–13 | `#26384A` |
| KPI 숫자 | Tableau Bold | 26–34 | 지표 강조색 |
| 본문·라벨 | Tableau Book | 10–11 | `#26384A` |
| 캡션(분모·조건) | Tableau Book | 9 | `#6B7784`(회색조) |

## 8. Action 설정표

| Action | 유형 | 원본 시트/개체 | 대상 | 실행 | 효과 |
|---|---|---|---|---|---|
| 화면 이동 | Navigation(이동) | 상단 네비 버튼 3개 | 대시보드 1/2/3 | 선택 | 워크북 내 화면 전환 |
| 구매차수 선택 | Parameter Action | D2 구매차수 버튼(도형 시트) | `P_구매차수` | 선택 | d2_경로비중·d2_누적곡선·d2_시간당비중 동시 갱신 |
| 경로 강조 | Highlight | d2_경로비중 | d2_경로비중(자기 강조) | 선택 | 선택 경로 원색 유지, 나머지 회색 흐림 |
| 경로 KPI 갱신 | Filter | d2_경로비중 | d2_kpi_최대경로 | 선택 | 선택 경로 건수·비중 표시 |
| 선택 해제 | (동작 없음) | 빈 공간 클릭 | — | 선택 해제 | 전체 복귀 |

설정 위치: `대시보드 → 동작 → 동작 추가`.

- **Navigation**: 개체 패널에서 `탐색` 버튼을 끌어다 놓고 대상 대시보드 지정(또는 `이동` 동작).
- **Parameter Action**: 원본 = 구매차수 버튼 시트, 대상 매개변수 = `P_구매차수`, 필드 = `구매차수`, 실행 = 선택.
- **누적곡선·시간당비중은 경로 클릭 대상에서 제외**한다(단일 경로 데이터). 경로 클릭은 Highlight + 경로 KPI만.
