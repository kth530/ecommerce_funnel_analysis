# Metrics 정의 및 데이터 처리 방침

방침의 집행은 `sql/02_preprocessing_mart.sql`에서 하고, 분석 노트북은 마트만 소비한다.

수치는 `notebooks/01_raw_eda.ipynb` 실행 출력 기준이며, 관측 기간은 2019-10-01 - 2020-02-29(전체 20,692,840행)이다.

## 1. 처리 방침

| 대상 | 방침 | 근거 (분자 / 분모 = 비율) | 출처 | 집행 위치 |
|------|------|---------------------------|------|-----------|
| 반복 이벤트 (4키: user_session·event_time·product_id·event_type) | 전 유형 미제거·수용 | purchase 905 / 1,287,007 = 0.070%; remove_from_cart 991,821 / 3,979,679 = 24.9%; cart 115,342 / 5,768,333 = 2.0%; view 1,031 / 9,657,821 = 0.011% | 01 §6 | 집행 없음(수용) — 왜곡 상한 명시 |

| price < 0 | 이벤트 카운트·revenue 모두 제외 | 131건 (purchase 집중·brand 전량 NULL → 반품/취소 추정) | 01 §5 | revenue 및 카운트 정의부 |
| price = 0 | 이벤트 카운트 포함, revenue 제외 | 104,157 / 20,692,840 = 0.50%; 2020-02 71,291 / 4,156,682 = 1.7% 급증 | 01 §5 | revenue 및 카운트 정의부 |
| 카테고리 키 | category_id 사용, category_code 미사용 | category_id 결측 0; category_code 98.291% 결측 | 01 §4, §11 | 마트 컬럼 선택 |
| 상품 대표 속성 | product_id별 category_id·brand 최빈값 사용. 동률이면 최종 관찰 시각 내림차순, 이후 값 오름차순 | 다중 category_id 상품 1,619 / 54,566 = 2.97%; 다중 brand 상품 24 / 54,566 = 0.044% | 04 §5 | `04_funnel_eda.sql` mart_product 생성부 |

- 반복 이벤트 미제거 사유: 제거 시 그룹 내 price 상이로 검증 불가능한 대표값 가정이 필요해 미제거가 방어 가능하다. purchase 초과 0.070%로 전환·revenue 왜곡 상한이 미미하다. remove_from_cart 카운트 해석 시 반복 가능성을 병기한다(03 인계).
- 유효 세션 >1일 제외 사유: 비활동 타임아웃 관례상 존재 불가능한 지속시간으로, 세션 ID 재사용이 의심된다.
- 상품 대표 brand는 NULL·빈 문자열을 후보에서 제외하며, 유효한 brand가 한 번도 없는 상품은 `unknown`으로 보존한다.

## 2. 지표 정의

- **유효 세션**: `user_session IS NOT NULL` AND 세션당 고유 `user_id` = 1 AND 지속시간(세션 내 `MAX(event_time) - MIN(event_time)`) ≤ 1일.
- **이벤트 도달(순서 미반영)**: 세션에 해당 이벤트가 1건 이상 있으면 도달로 본다(`views > 0`, `carts > 0`, `purchases > 0`). 각 도달 집합은 독립적으로 집계하며 포함 관계를 가정하지 않는다. 03의 도달·분포 집계가 이 정의를 사용한다.
- **세션 진입·이탈 유형**: `first_event_type`·`last_event_type`은 `session_start`·`session_end`와 동일하게 유효 세션 내 전체 이벤트를 기준으로 한다(`price` 필터 미적용). 세션 경계의 보조 기술값이며 순차 퍼널과 직접 진입 경로 판정에는 사용하지 않는다.
- **구매 세션 도달률** = `purchases > 0`인 유효 세션 수 / 유효 세션 수. 이벤트 순서를 반영하지 않으므로 순차 전환율과 구분한다.
- **strict 순서**: 앞선 행동의 `event_time`이 뒤 행동보다 작은 경우(`<`)만 선후가 확인된 것으로 본다. `strict`는 시간 비교 방식이며, 반드시 `view → cart → purchase` 3단계를 모두 거쳤다는 뜻은 아니다.
- **세션 전체 3단계 순차 퍼널**: 분석 단위는 세션(`user_session`)이다. 같은 세션 안에서 strict 시간순 `view → cart → purchase`가 확인되면 3단계 순차 도달로 본다. 상품 동일 조건은 적용하지 않으므로 서로 다른 `product_id`의 이벤트가 한 경로로 연결될 수 있다.
- **세션 view→cart 순차 전환율** = 같은 세션에서 view 이후 cart가 발생한 세션 수 / view 도달 세션 수.
- **세션 cart→purchase 순차 전환율** = 같은 세션에서 `view → cart` 이후 purchase가 발생한 세션 수 / `view → cart` 순차 도달 세션 수.
- **세션 3단계 완주율** = 같은 세션에서 strict `view → cart → purchase`가 확인된 세션 수 / view 도달 세션 수. cart 경유를 필수로 하는 특정 경로의 완주율이며, cart를 거치지 않은 `view → purchase`는 포함하지 않는다.
- **strict view→purchase**: 동일 구매 에피소드 안에서 view가 purchase보다 앞선 경로다. 이 집합은 중간의 유효한 cart가 확인된 경로와 확인되지 않은 경로를 모두 포함한다. `strict view→cart→purchase`는 그중 중간 cart가 확인된 부분집합이다.
- **동일 상품 3단계 순차 퍼널**: 분석 단위는 세션·상품(`user_session × product_id`)이다. 같은 세션·같은 상품에서 strict 시간순 `view → cart → purchase`가 확인되면 3단계 순차 도달로 본다.
- **동일 상품 view→cart 순차 전환율** = 같은 세션·상품에서 view 이후 cart가 발생한 session-product 수 / view 도달 session-product 수.
- **동일 상품 cart→purchase 순차 전환율** = 같은 세션·상품에서 `view → cart` 이후 purchase가 발생한 session-product 수 / `view → cart` 순차 도달 session-product 수.
- **동일 상품 3단계 완주율** = 같은 세션·상품에서 strict `view → cart → purchase`가 확인된 session-product 수 / view 도달 session-product 수.
- **사용자·상품 N일 구매 도달률** = 관측 기간 내 사용자·상품별 최초 view가 있고 그 이후 N일을 끝까지 관측할 수 있는 조합 중, 해당 view보다 나중이면서 N일 이내인 동일 상품 purchase가 확인된 조합의 비율. 한 사용자·상품을 분모에서 한 번만 세며, 최초 view는 생애 최초가 아니라 관측 기간 내 최초 view다. 04의 세션 내 3단계 완주율과 분석 단위·관측 기간이 다른 별도 지표로 관리한다.
- **view·purchase 동반, cart 미도달 세션**: `views > 0 AND carts = 0 AND purchases > 0`인 세션이다. 세 이벤트의 존재 여부만 확인한 경계 집계이므로 strict `view → purchase`를 뜻하지 않는다. 정확한 선후와 구매 에피소드 안의 중간 cart 여부는 06에서 이벤트 시각으로 판정한다.
- **직접 진입 경로**: 선행 단계 없이 cart 또는 purchase가 관찰된 세션·session-product는 순차 전환 분자에서 제외하고 선형 퍼널 밖 경로로 별도 집계한다. 세션 내 미구매는 관측 기간 전체의 구매 포기나 사용자 이탈을 의미하지 않는다.
- **상품 이벤트 비율** = 상품·카테고리·가격대별 cart 또는 purchase 이벤트 수 / view 이벤트 수. 이벤트 개수 비율이며 순서와 도달 단위를 반영하지 않아 순차 전환율과 직접 비교하지 않는다.
- **revenue** = `event_type = 'purchase'` AND `price > 0` 인 이벤트의 `price` 합.
- **카테고리 키** = `category_id`.
- **상품 대표 속성**: `mart_product`의 category_id·brand는 상품별 최빈값이다. 동률이면 마지막 관찰 시각이 늦은 값을 우선하고, 그래도 동률이면 값 오름차순으로 하나를 선택한다.
- **이벤트 카운트**(views·carts·removes·purchases): `price < 0` 이벤트는 모든 카운트에서 제외한다. `price = 0`은 카운트에 포함한다.

## 3. 구매 여정 정의

- **구매 분석 단위**: 대표 분석 단위는 purchase가 1건 이상 있는 `user_session × product_id`다. 한 세션·상품의 여러 purchase 이벤트를 서로 다른 구매로 임의 분리하지 않고 `purchases`, `first_purchase_at`, `last_purchase_at`으로 보존한다. 다중 purchase 세션·상품은 규모를 별도 제시하고 결과 민감도를 확인한다.
- **관측 첫 구매·반복 구매**: 같은 `user_id × product_id`에서 현재 `first_purchase_at`보다 이른 purchase가 없으면 관측 첫 구매, 있으면 관측 반복 구매로 분류한다. 생애 첫 구매·재구매를 뜻하지 않으며 관측 기간 안에서만 판정한다.
- **구매 에피소드 경계**: 현재 구매보다 앞선 가장 최근 동일 상품 purchase를 이전 에피소드의 종료로 본다. 현재 구매에 연결할 view·cart·remove 후보는 원칙적으로 이전 purchase보다 늦고 현재 `first_purchase_at`보다 이른 행동만 사용한다. 이전 구매에 사용됐을 수 있는 오래된 행동을 현재 구매에 다시 연결하지 않는다.
- **구매 차수와 경로의 분리**: 관측 첫 구매·반복 구매는 구매 차수 축, 현재 구매 세션 완결·다른 세션 cart 연결 등은 경로 축으로 별도 판정한 뒤 결합한다. 반복 구매를 우선 배정해 다른 경로 정보를 버리지 않는다.
- **구매 경로 우선순위**: 구매 에피소드 안에서 ① 현재 구매 세션·상품의 strict `view → cart → purchase`, ② 현재 구매 전에 확인된 가장 가까운 cart가 현재 purchase와 다른 `user_session`에 있으면 다른 세션 cart 연결, ③ 가장 가까운 cart가 현재 구매 세션에 있으나 완전한 view 경로가 없으면 현재 구매 세션 cart→purchase, ④ cart가 없고 가장 가까운 view가 다른 세션이면 다른 세션 view 연결, ⑤ view가 현재 구매 세션에만 있으면 현재 구매 세션 view→purchase, ⑥ 구매 전 view·cart 미확인 순으로 하나를 부여한다. `다른 세션`은 바로 직전 세션이나 완전히 먼저 끝난 세션만을 뜻하지 않는다. 동일 시각 행동은 대표 경로에서 제외하고 판정 불가 규모를 별도 기록한다.
- **구매 전 cart 구분**: 겹치지 않게 나눈 구매 경로 중 `현재 구매 세션 view→cart→purchase`, `다른 세션 cart→현재 purchase`, `현재 구매 세션 cart→purchase`는 구매 전 cart 확인으로 묶고, 나머지 세 경로는 구매 전 cart 미확인으로 묶는다. 미확인은 동일 상품의 이전 구매 이후부터 이번 구매 전까지 cart를 찾지 못했다는 뜻이며 실제 cart 미경유 구매를 확정하지 않는다.
- **지연 구매 후보**: 관측 첫 구매·반복 구매 여부와 별개로, 구매 에피소드 안에서 다른 세션의 cart가 현재 purchase보다 먼저 확인된 경로다. 장바구니 상태 자체를 관측한 것이 아니므로 지연 구매 확정으로 표현하지 않는다.
- **remove 직전 상태 신호**: 같은 세션·상품에 cart·purchase 없이 remove만 있는 조합에서 `first_remove_at`보다 이른 동일 사용자·상품의 cart·purchase·remove 최근 시각을 비교한다. 과거 cart가 한 번이라도 있었는지는 넓은 이력 참고값으로 보존하고, 세 상태 중 가장 최근 시각이 cart인 경우를 더 강한 장바구니 이월 후보로 분류한다. 가장 최근 시각이 둘 이상 동일하면 순서를 판별할 수 없으므로 `동일 시각 순서 주의`로 분리한다. 직전 상태가 cart여도 실제 장바구니 상태 유지가 입증된 것은 아니다.
- **remove 상태 미확인 월별 민감도**: remove 발생 월별로 직전 상태 이벤트 미확인 비율을 계산한다. 좌측 절단의 방향 확인은 관측 시작 월인 2019-10과 2019-11-2020-02 통합 비율을 비교하고, 개별 월 추이는 보조로 제시한다. 관측 초반의 높은 미확인은 좌측 절단과 정합하는 신호일 뿐 기여분이나 원인을 확정하지 않는다.
- **우측 절단**: 행동 이후 N일 구매 도달률은 `anchor_at + INTERVAL N DAY <= observation_end`인 기준점만 분모에 포함한다. 즉 기준 행동 이후 N일을 끝까지 관측해 구매 여부를 판정할 수 있는 조합만 사용한다. 이 식은 `anchor_at <= observation_end - INTERVAL N DAY`와 같으며, N일을 끝까지 볼 수 없는 기준점은 N일 지표에서 제외하고 제외 규모를 함께 제시한다.
- **동일 분모 3단계 비교**: 최초 view 이후 N일을 끝까지 관측할 수 있는 동일한 `user_id × product_id` 조합을 분모로 둔다. 04식 동일 세션 3단계 완주는 같은 세션·동일 상품에서 strict `view → cart → 첫 purchase`가 N일 안에 확인된 조합이며, `has_view_cart_before_first_purchase = 1`과 `first_purchase_at`으로 판정한다. 이를 **세션 통합 N일 동일 상품 구매 도달**과 나란히 제시한다. 세션 통합 지표는 같은 사용자의 동일 상품 행동을 여러 세션에 걸쳐 모으며 cart 유무를 제한하지 않는다. 두 분자의 차이는 **동일 세션 3단계 밖 구매**이며 세션 간 구매만을 뜻하지 않는다.
- **CRM 실험 적격 기준선**: `mart_user_product_session.first_cart_at`을 cart 기준 시각의 근사값으로 사용하고, 사용자별 관측 기간 내 최초 cart 한 건만 후보로 둔다. 같은 사용자의 여러 상품이 최초 시각에 동시에 기록되면 `product_id`가 작은 한 건을 재현 가능한 대표값으로 선택한다. 이 cart 이후 24시간 동안 동일 상품 purchase가 없으면 `cart+24시간`을 실험 적격 시점으로 두며, 24시간 안에 구매한 사용자는 이후 cart로 재진입시키지 않는다. 주지표 기준선은 적격 시점 이후 7일 안에 동일 상품 purchase가 확인된 사용자 수 / 적격 시점 이후 7일을 끝까지 관측할 수 있는 적격 사용자 수다. 이는 구매 성공 에피소드만 분모로 둔 cart→purchase 시간 분포와 다른 지표다. 최초 cart만 사용하는 1회성 설계이므로 반복 적격을 허용하는 운영 모집단보다 규모가 작을 수 있다. 현재 마트는 세션·상품의 최초·최종 시각만 보존하므로 운영 시스템의 개별 cart 트리거와 동일한 모집단이 아니라 근사 기준선으로 사용한다. remove·후속 cart·수신 동의·상품 판매 상태는 현재 기준선 분모에서 확정하지 않고 실제 발송 직전에 별도 확인한다.
- **최초 cart 이후 일별 동일 상품 구매 위험률**: 사용자별 관측 기간 내 최초 cart 한 건을 기준으로 7일 전체를 관측할 수 있는 공통 cohort를 만든다. 각 24시간 구간의 분모는 해당 구간 시작까지 동일 상품을 구매하지 않은 사용자 수, 분자는 구간 시작 초과·종료 이하에 최초 동일 상품 purchase가 확인된 사용자 수다. 예를 들어 24-48시간 위험률은 첫 24시간 안에 구매한 사용자를 제외한 위험집단에서 계산한다. 구매 성공자만 분모로 둔 cart→purchase 시간 분포와 다르며, 관찰 로그의 구간별 자연 구매 신호이지 메시지 발송 효과나 최적 시점을 뜻하지 않는다.
- **CRM 실험 지표 기준점**: 무작위 배정·발송·성과 관측의 기준점은 `cart+24시간`으로 통일한다. 주지표는 기준점 이후 7일 내 동일 상품 구매 사용자 비율, 단기 보조지표는 기준점 이후 1일 내 동일 상품 구매, 장기 보조지표는 기준점 이후 30일 내 동일 상품 구매다. 7일 개선이 30일에 사전 정의한 실질적 동등 범위 안으로 축소되면 구매 시점 이동과 정합하는 신호로 보되, 30일 결과가 통계적으로 유의하지 않다는 이유만으로 시점 이동을 확정하지 않는다.
- **CRM 실험 표본·판정**: 실험 단위는 `user_id`, 배정은 1:1이다. 기준선 구매율에서 상대 개선폭 5%·10%를 MDE 시나리오로 두고 양측 유의수준 5%·검정력 80% 기준의 두 비율 차이 표본을 계산한다. 모집 기간은 관측 기간 전체 일평균 적격자 수와 28일 이동평균의 하위 25%를 함께 제시한다. 전자는 과거 평균을 그대로 적용한 최소치, 후자는 트래픽 변동을 반영한 보수적 시나리오이며 실제 운영에서는 수신 동의·장바구니 잔존·재고 조건을 적용해 다시 계산한다. MDE는 표본 설계값이며 성공 판정선으로 대신 쓰지 않는다. 주지표는 사전에 합의한 실질적 최소 개선폭과 신뢰구간으로 판단하고, 수신 거부·신고·전체 상품 구매 건수·전체 상품 revenue는 사업 담당자가 사전 승인한 비열등성 한도 안에 있어야 한다. 한도를 하나라도 벗어나면 주지표가 개선돼도 전체 롤아웃하지 않는다. 정확한 한도는 현재 행동 로그로 임의 설정하지 않는다.
- **좌측 절단**: purchase 이전 N일 행동을 찾는 분석은 `purchase_at >= observation_start + INTERVAL N DAY`인 구매만 N일 lookback의 완전 관측 분모에 포함한다. 전체 과거를 사용하는 결과는 관측 시작 이전 행동이 잘린 값임을 명시하고 월별 또는 lookback 기간별 민감도를 함께 확인한다.

## 4. 예외

- **동일 시각 이벤트**: `event_time`이 같은 이벤트에는 보조 순번이 없어 시간순 선후를 식별할 수 없다. 순차 퍼널의 대표값은 선후가 확인되는 strict(`<`) 기준으로 계산하고, 동일 시각을 인정하는 inclusive(`≤`) 결과는 02 검증에서 민감도만 기록한다. 유효 세션·`price >= 0` 범위에서 inclusive 적용 시 세션 view→cart는 710,008→710,651(+643, 전환율 +0.015%p), view→cart→purchase는 97,600→97,628(+28)이고, 동일 상품 view→cart는 885,651→887,130(+1,479, +0.018%p), view→cart→purchase는 132,235→132,425(+190)로 대표값을 바꿀 수준의 차이는 아니다. 이 inclusive 수치는 `02_preprocessing_mart.ipynb`의 `RUN_SESSION_MART_VALIDATION=True` 실행 시점에 raw 독립 집계로 확인해 기록한 값이다. 이후 장시간 raw 재집계를 피하려고 기본값을 `False`로 두었고, 현재 커밋된 노트북 출력의 `동일 시각 민감도 재계산 생략`은 검증 실패가 아니라 재집계를 건너뛴 상태를 뜻한다. 마트의 순서 정의나 원본 데이터가 바뀔 때만 스위치를 켜 재확인하며, 대표값은 strict를 유지하고 inclusive는 동일 시각 처리 민감도 확인용으로만 사용한다.
- **세션 경계**: 04의 순차 퍼널은 같은 세션 안의 경로만 다룬다. 이전 세션의 view·cart 이후 후속 세션에서 발생한 purchase는 04의 순차 전환에서 제외하고 05 사용자·상품 여정에서 별도 분석한다.
- **상품 범위**: 세션 전체 순차 퍼널은 방문 수준의 행동 진행을 보기 때문에 상품 동일 조건을 두지 않는다. 상품·카테고리·가격대별 전환은 `user_session × product_id` 기준의 동일 상품 순차 퍼널만 사용한다.
